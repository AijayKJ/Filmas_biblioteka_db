# Filmu Bibliotēka

Šī ir vienkārša un ērta Python lietojumprogramma ar grafisko interfeisu (GUI), kas ļauj pārvaldīt filmu bibliotēku un glabāt datus SQLite datubāzē.

---

## Galvenās iespējas

* **5 Savstarpēji saistītas tabulas:**
  * **Movies** (Filmas)
  * **Actors** (Aktieri)
  * **Directors** (Režisori)
  * **Genres** (Žanri)
  * **Users** (Lietotāji)
* **Pilns CRUD cikls:** Iespēja pievienot, apskatīt, labot un dzēst ierakstus.
* **Automātiska datubāze:** Programma pati izveido datubāzi un testa datus pirmajā palaišanas reizē.
* **Drošība:** Ieslēgtas ārējās atslēgas (`Foreign Keys`) datu integritātei.

---

## Izmantotās tehnoloģijas

* **Python 3**
* **Tkinter & TTK** (Grafiskais interfeiss)
* **SQLite3** (Datubāze)
